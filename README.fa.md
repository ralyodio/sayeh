# سایه

*یک پیام، داخل یک پیام دیگر.*

---

یک پیام معمولی می‌فرستی — «سلام، خوبی؟» — و همان پیام، بی‌آنکه چیزی پیدا باشد، یک متن محرمانه هم با خودش می‌برد. هر کسی چت را ببیند فقط «سلام، خوبی؟» را می‌بیند. طرف مقابلت اما پیام واقعی را از دلش بیرون می‌کشد.

کار سایه همین است: داده را با نویسه‌های نامرئی یونیکد لای یک متن عادی می‌بافد. متن سرجایش می‌ماند و خوانا؛ پیام پنهان می‌شود لای همان حروف.

و بهترش: روی پیامِ پنهان یک **رمز** بگذار. حالا پیام از هر مسنجری رد می‌شود، و آن شرکت هرچقدر هم چت‌هایت را نگه دارد و بخواند، این یکی را باز نمی‌کند. زیرِ کار Argon2id و XChaCha20-Poly1305 است — همان رمزنگاری‌ای که برای دادهٔ جدی به کار می‌رود. بدون رمز، فقط بایتِ به‌هم‌ریخته می‌بیند.

رمز اجباری نیست؛ برای یک پیامِ سرسری بدون رمز هم کار می‌کند. ولی هر وقت محتوا مهم بود، رمز همان چیزی است که ازش محافظت می‌کند.

## امتحانش کن

```bash
cargo build --release -p sayeh-cli

sayeh hide --cover "سلام، کی میای؟" --secret "ساعت ۹ دمِ در" --output out.txt
sayeh scan   --input out.txt      # ببین چی داخلش هست، بدون بازکردن
sayeh reveal --input out.txt      # و بازش کن
```

`out.txt` را که باز کنی، همان «سلام، کی میای؟» است — با چند صد نویسهٔ نامرئی که لایش نشسته و چشم نمی‌بیندشان. رمز را موقع `hide` می‌پرسد و روی صفحه نشان نمی‌دهد.

نمی‌خواهی چیزی نصب کنی؟ پوشهٔ [`demo/`](demo/) یک نسخهٔ مرورگری است که همه‌چیز را داخل خودِ صفحه اجرا می‌کند — بدون سرور، بدون اینکه داده‌ای جایی برود.

## با فارسی سر جنگ ندارد

بیشتر ابزارهای این‌مدل، متن فارسی را خراب می‌کنند. سایه دو نویسه را عمداً هیچ‌وقت دست نمی‌زند: **`U+200C`**، همان نیم‌فاصله، تا «می‌روم» و «کتاب‌ها» سالم بماند؛ و **`U+200D`**، همان چسبِ ایموجی، تا ایموجی‌های ترکیبی مثل «خانواده» از هم نپاشند. پاک‌سازیِ امن هم همین دو را نگه می‌دارد.

پیش‌فرض روی چهار نویسهٔ نامرئیِ دیگر کار می‌کند و اگر جای بیشتری خواستی، سه حاملِ متراکم‌تر هم هست.

## دو راه برای قفل‌کردن

**با رمز.** یک عبارت که تو و مخاطبت می‌دانید. برای یک پیام گاه‌به‌گاه عالی است.

**با کلید مخاطب.** یک بار کلید عمومی همدیگر را رد و بدل می‌کنید و حضوری تأیید؛ از آن به بعد هیچ رمز مشترکی لازم نیست. زیرِ کار X25519 و HKDF است، ساخته‌شده برای یک گفت‌وگوی ادامه‌دار. روی خط فرمان کامل است؛ رابط اندرویدش در راه است.

## دستورها

| دستور | کار |
|---|---|
| `hide` / `reveal` | پنهان‌کردن و بازکردن پیام |
| `scan` | گزارش محتوای یک متن، بدون بازکردن |
| `strip` | پاک‌کردن نویسه‌های نامرئی از یک متن |
| `analyse` | سنجش اینکه پیام چقدر راحت لو می‌رود |
| `probe` | ساخت متن آزمایشی برای دیدن اینکه کدام مسنجر نویسه‌ها را زنده رد می‌کند |
| `capacity` | اینکه یک راز چقدر ظرفیت لازم دارد |
| `identity` / `contact` | کلید خودت و دفترچهٔ مخاطبان |

`sayeh <command> --help` جزئیات هرکدام را می‌دهد.

## اندروید و مرورگر

اپ اندروید با Kotlin و Jetpack Compose نوشته شده و منطقش را از همین هستهٔ Rust می‌گیرد — رمزنگاری در لایهٔ رابط تکرار نشده. زمانِ ساختِ کلید با Argon2id را روی یک گوشیِ واقعی (شیائومی، ARM64، اندروید ۱۳) گرفتیم: حدود ۶۰۰ میلی‌ثانیه. نسخهٔ مرورگری هم همه‌چیز را با wasm داخل صفحه اجرا می‌کند.

## از سورس

```bash
cargo test  --workspace --all-features
cargo build --release -p sayeh-cli
```

حداقل نسخهٔ Rust برابر ۱٫۸۵ است. مسیر ساخت APK اندروید در [README انگلیسی](README.md) آمده.

## کجای کار است

نسخهٔ پیش‌انتشار از قالب v4. قالب بایتی در [SPEC.md](SPEC.md) و بردارهای آزمونِ مستقل در [`vectors/`](vectors/) هستند، تا هر پیاده‌سازی دیگری خودش را با آن بسنجد. نسخهٔ قدیمی‌ترِ v3 (پیاده‌سازی Go و اندروید) هم در [`legacy/v3/`](legacy/v3/) نگه داشته شده.

سایه پیام را نامرئی می‌کند، نه ردیابی‌ناپذیر: کسی که به متن دقیق شود می‌تواند بفهمد چیزی لایش هست. چه چیزی محافظت می‌شود و چه چیزی نه، صادقانه در [SECURITY.md](SECURITY.md) نوشته شده.
